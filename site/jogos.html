Jogos livres

Jogos homebrew e freeware, feitos por fãs e estúdios independentes para os consoles clássicos, com licença que permite baixar e compartilhar. Baixe um por um, o pacote de cada console ou tudo de uma vez, e coloque na pasta Jogos do app.

⚖️

Por que só jogos livres?

Jogos comerciais (Nintendo, Sega, Sony, SNK…) têm direitos autorais: só quem tem a licença pode distribuí-los. Aqui ficam apenas jogos cujos autores permitem a distribuição, com o link para o site de cada um.

💾

E os meus jogos?

Use cópias dos cartuchos e discos que você possui. O manual mostra como levar os arquivos para a TV ou para o celular.

🛠️

Fez um homebrew?

Abra uma sugestão no GitHub com o nome, a licença e o link oficial do seu jogo para ele entrar aqui.
